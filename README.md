# Friendly Pet — сайт груминг-салона

Статический сайт, подготовленный для публикации на GitHub Pages.

## Структура

```text
friendly-pet-site/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── images/
│   └── icons/
├── .nojekyll
└── README.md
```

## Локальный просмотр

Откройте `index.html` в браузере. Для проверки поведения лучше использовать локальный сервер (например, расширение Live Server в VS Code).

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите содержимое этой папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.
5. Дождитесь публикации и откройте выданный GitHub Pages URL.

## Перед передачей заказчику

- Заменить демонстрационные блоки-заглушки на согласованные фотографии.
- Проверить актуальность цен, адреса, телефона, отзывов и ссылок.
- Убедиться, что владелец салона разрешил использовать отзывы, фотографии и контактные данные.
- Проверить кнопки записи и связи на телефоне.
- При необходимости добавить favicon и политику обработки персональных данных для форм, если они появятся.

## Примечание

Стили и скрипты вынесены из исходного HTML в отдельные файлы без намеренного изменения дизайна или логики. Внешний шрифт загружается из Google Fonts.
